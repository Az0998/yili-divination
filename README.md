# 易理占筮 · 太极八卦六十四阵

纯前端《周易》象数与韦特塔罗学习站：一事一占、事不过三、因地制宜、天时地利人和、六爻梅花、体用生克、朱熹动爻玩辞法。  
动态背景：太极 · 先天八卦 · 六十四卦阵。

> 在线演示（个人站）：https://zhangsjqaq.vexr.dev/yili  
> 作品集：https://zhangsjqaq.vexr.dev

## 快速开始

```bash
# 直接用浏览器打开 index.html
# 或本地静态服务
python -m http.server 8080
```

访问 http://localhost:8080

## 复杂问事（漏斗筮法）

迁居择城、职业赛道、升学择途、合作人选、姻缘比较、投资取向、多方案决择：

1. **立界** — 目标与约束  
2. **缩圈** — 八字简盘喜用 + 方位五行，筛 3–6 候选  
3. **正断** — 每一候选单独梅花起卦（一事一占）  
4. **排序** — 体用玩辞为主，命理缩圈为辅  

打开页面后切换到 **「复杂问事」** 标签即可。

## 功能

1. **净心立问** — 诚意确认 + 一事一问 + 事件类型  
2. **三才备物** — 天时 / 地利（先天方位） / 人和  
3. **择筮成卦** — 六爻三钱 · 时间/人物/方位/报数梅花  
4. **观象玩辞** — 本卦（贞）· 之卦（悔）· 动爻法则 · 体用五行  
5. **追问（事不过三）** — 同一事可澄清两层，三筮则不告  
6. **因地制宜** — 依事类与地气方位给参考解卦词  
7. **西占·塔罗** — 韦特 78 张，单张/三张/二选一/关系/马蹄/凯尔特十字，可与梅花对照
